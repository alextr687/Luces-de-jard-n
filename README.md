# Luces de jardín

Este repositorio consiste en una serie de soluciones para iluminar el jardín, pero siguiendo una filosofía de diseño muy clara: no iluminar. Las luminarias de exterior son perjudiciales para la fauna silvestre, y suponen una inversión económica significativa con poco (o ningún) rendimiento. Los sistemas de iluminación aquí presentes buscan añadir luz al ambiente, guiar al usuario o simplemente decorar, sin ser elementos disruptivos al ambiente. 

## Setas

![Instalación terminada de setas luminosas](setas/images/setas_instaladas.jpg)

Son una solución simple, con el objetivo de marcar los límites de un camino (por ejemplo), sin llamar la atención, tanto de día como de noche. Más información al respecto en [la carpeta de setas](setas).

## Mariquitas

![Instalación terminada de mariquitas luminosas](mariquitas/images/foto_dia.jpg)

Se trata de una instalación que permite iluminar la forma de un árbol, pero sin desentonar ni resultar molesta. Lógicamente, puede utilizarse también para iluminar fachadas u otros elementos mayoritariamente verticales. Más información en [la carpeta de mariquitas](mariquitas).
